# javascript-racingcar-precourse

## ✅ 기능 구현 목록

- [x] 자동차 이름 입력받기
  - [x] `,` 기준으로 이름 구분
    - [x] `,` 기준으로 이름 구분 가능한지 확인
  - [x] 자동차가 2개 이상인지 확인
  - [x] 이름 5자 이하인지 확인
- [x] 이동 시도할 횟수 입력받기
- [x] 자동차마다 무작위 값 구해 4 이상인 경우 전진
  - [x] 이동 횟수만큼 반복
- [x] 우승자 구하기
  - [x] 여러 명인 경우 `,`로 구분
- [x] 잘못된 값 입력 시 에러 발생 후 종료
